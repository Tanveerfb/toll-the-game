  • NewThe party strip is the feature. Four bars that survive tile boundaries. Everything else on this screen is navigation; this is the only element that remembers, and it's what turns four fights into a run.
  • A11yTile type is carried by shape, not colour. Circle scene, diamond fight, hexagon event, star boss — so the map still parses without colour vision, and the legend names all four. Same rule on the downed unit: an ✕ glyph and the words "out for the run", never a red bar alone.
  • NewA fork states both costs before you commit. The long way heals, the short way doesn't. Unlit paths stay low-contrast; only reachable nodes are tappable, and the walked path is drawn in dim signal so the route reads as history behind you.
  • NewBoss is the heaviest node — biggest glyph, gold, its own halo, and it says the route ends there. It's the only node that pays out.
  • ChangedScenes and the versus splash survive as-is, entered from a node instead of a fixed slot in a linear flow. No existing screen is thrown away.
  • A11yNodes are real buttons: role="button", tab-reachable, 44px+ hit area, visible focus ring. The "you are here" pulse is behind prefers-reduced-motion.

Open question for you: the event tile above heals. That's the only release valve attrition has, and it's a mechanic — so its size (flat %? scaling? full?) is yours to set, not mine. Same for whether an event tile can also hurt.

  • NewRoute preview, forks included. Without it the player pays 12 stamina for an unknown length. It's the same glyph vocabulary as the stage, so the map is already familiar the first time it's walked.
  • NewThe rule box. Three rules that cannot be discovered safely by playing. This is where ruling #96's deleted sentence effectively returns — as the rule that needed stating, not the team-mode one.
  • ChangedThe bench slot becomes a real decision. Subs exist to absorb a death, and attrition is the first mechanic that makes them matter, so the slot says what it's for.
  • Changed"Against" → "Boss". Printing every enemy on every tile would be a wall; name the boss, count the rest.
  • ChangedSkip story → Farm run. On a cleared chapter it collapses the route to the fight that pays. Attrition belongs to first clears; grinding stays fast.
  • KeptFact strip, stage-effect chips, insufficient-stamina notice, trial/owned anchor toggles, back button naming.
